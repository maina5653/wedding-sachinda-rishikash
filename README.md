# Sachinda & Rishikash — Wedding Invitation

A responsive royal ivory-and-gold wedding website.

## Wedding details

- **Date:** 10 December 2026
- **Time:** 1:00 PM–6:00 PM
- **Venue:** [Open in Google Maps](https://maps.app.goo.gl/njDaUTVqwXMzF4XYA)

## RSVP

The RSVP is currently website-only. Responses are saved in the guest’s browser using `localStorage` and remain available on the same device/browser. For collecting responses centrally, connect the form to a backend or hosted form service.

## Run locally

Open `index.html` directly in a browser, or serve the folder with:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
